# Identidad de Marca — Estética Patri

Recursos visuales y especificaciones de identidad gráfica obtenidos desde la carpeta `ProyectosPersonales`.

---

## 1. Archivos Disponibles

- **`logo_estetica_refinado.svg`**: Isotipo vectorial de la marca (silueta femenina estilizada con acentos en negro profundo sobre un círculo degradado rosa).
- **`paleta_tipografia_estetica.svg`**: Muestra gráfica completa de la paleta cromática y especificaciones tipográficas.
- **`identidad_marca_mockup.png`**: Render y mockup visual de la aplicación de marca.

---

## 2. Paleta de Colores

| Rol de Color | Valor HEX | Uso Recomendado |
| :--- | :---: | :--- |
| **Rosa principal** | `#FF9CAC` | Marca, botones primarios, acentos destacados |
| **Rosa claro** | `#FFD6DC` | Superficies, tarjetas, contenedores suaves (`PrimaryContainer`) |
| **Negro profundo** | `#111111` | Textos de alto contraste, isotipo, títulos principales |
| **Marfil cálido** | `#F7F4F2` | Fondo de pantalla alternativo / modo claro limpio (`Surface`) |
| **Rosa suave** | `#E89CB0` | Acentos secundarios, bordes sutiles, estados intermedios |

---

## 3. Tipografía

- **Familia principal:** **Montserrat**
  - **Títulos:** SemiBold (peso 600)
  - **Texto y botones:** Regular / Medium (pesos 400 y 500)
- **Fallback / Sistema Android:** Roboto / Sans-serif nativo de Android.
